Tableau de classe

  1. Chaque élève ouvre sa page Profil, indique son prénom et clique sur « Code pour mon professeur ».
  2. Il vous envoie ce code par l'ENT, par message ou dans un document partagé.
  3. Collez ici tous les codes reçus, en vrac : le texte autour des codes est ignoré.

Tout est calculé dans ce navigateur. Les codes collés y restent enregistrés jusqu'à ce que vous les effaciez ; rien n'est envoyé sur Internet.
